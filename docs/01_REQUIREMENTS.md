# 01. 要件定義書

- 対象: line-send
- 作成日: 2026-10-10
- 改訂: 2026-10-10（評価で決めた制約と未決の確定を反映）
- 関連文書: [02_SPECIFICATION.md](02_SPECIFICATION.md) / [03_STRUCTURE.md](03_STRUCTURE.md)

## 1. 背景

スマホで「この日時にこれを思い出させて」と予約し、その時刻に自分の LINE で受け取りたい、という需要があります。普段から見ている LINE に届けば見落としにくいです。LINE Notify は 2025 年 3 月に終了したため、LINE 公式アカウントの Messaging API で送ります。

## 2. 目的

スマホから文面と日時を入れるだけで、その時刻に自分の LINE へリマインダーが届くようにします。篠田が 1 か所でホストし、承認した友達も同じように使えるようにします。

## 3. 対象範囲

### 3.1 対象

- スマホ向けの予約画面（LIFF + PWA）
- 1 回きりの日時指定リマインダー（作成・一覧・取り消し）
- 指定時刻での LINE 送信（1 分に 1 件。同じ分に重なった分は次の分へ送る）
- LINE アカウントによる本人確認と利用申請
- 管理者による申請の承認・却下
- 利用者ごとの月間送信上限と、チャネル全体の余裕
- 退会（承認済みと申請中だけ。管理者と却下済みは退会できない）

### 3.2 対象外

| 項目 | 扱い |
| --- | --- |
| スクリプトから送る HTTP API（API キー方式） | 後回し。将来追加できるよう API は画面と分けて作る |
| 繰り返し予約（毎日・毎週など） | 対象外 |
| 予約の編集 | 対象外。変えるときは取り消して作り直す |
| 本人以外への送信 | 対象外。誤送信・悪用を防ぐ |
| 画像・Flex Message | 対象外。テキストのみ |
| ネイティブアプリ（React Native） | 対象外。PWA で足りる |
| オフライン動作 | 対象外 |
| 承認したときの LINE 通知 | 対象外。送信枠を予約に使う |
| 同じ内容の二度押し防止 | 初版は対象外 |

## 4. 利用者

| 利用者 | 説明 |
| --- | --- |
| 管理者 | 篠田。システムをホストし、申請を承認する。自分のリマインダーにも使う。退会できない |
| 一般利用者 | 篠田の友達。申請して承認されると使える |

## 5. 機能要件

| ID | 要件 |
| --- | --- |
| FR-01 | 利用者はスマホで文面と日時を入力してリマインダーを予約できる |
| FR-02 | 予約した日時になると、予約した本人の LINE にテキストが届く。宛先は指定できない |
| FR-03 | 送信は 1 分に 1 件とする。同じ分に複数あれば、1 件ずつ次の分へ送る |
| FR-04 | 予約は 1 回きりとする |
| FR-05 | 利用者は自分の予約を一覧で確認できる（送信待ち・送信中・送信済み・失敗） |
| FR-06 | 利用者は `scheduled` の予約だけ取り消せる。送信中は取り消せない |
| FR-07 | 画面は LINE 公式アカウントのメニューから開ける（LIFF）。このとき自動で本人確認される |
| FR-08 | 画面はブラウザやスマホのホーム画面からも開ける（PWA） |
| FR-09 | 公式アカウントを友だち追加していない人には追加を促す |
| FR-10 | 利用は誰でも申請できる。管理者が承認するまで予約できない。却下後の再ログインは `rejected` のままである。却下された人は退会できない。管理者はあとから承認できる |
| FR-11 | 管理者は管理画面で申請を承認・却下できる。却下すると、その利用者の送信待ち予約は削除される |
| FR-12 | 利用者ごとに月間の送信上限を設ける。上限を超える予約は作成時に拒否する |
| FR-13 | 月間上限の値は設定で変更できる。既定は 30 である。下げても、既に作った予約は消さない |
| FR-14 | 利用者は当月の予約数と上限を画面で確認できる |
| FR-15 | 承認済みと申請中の利用者は退会できる。退会すると予約もすべて削除される。管理者は退会できない |
| FR-16 | 管理者は、環境変数に登録した LINE userId の人とする |
| FR-17 | 承認後の active 人数 × 月間上限が 180 を超える承認は拒否する |

## 6. 非機能要件

| ID | 区分 | 要件 |
| --- | --- | --- |
| NFR-01 | セキュリティ | 秘密情報（LINE のトークン等）をリポジトリに含めない。リポジトリは Public |
| NFR-02 | セキュリティ | 本人確認はサーバー側で LINE の ID トークンを検証して行う |
| NFR-03 | セキュリティ | 他人の予約を閲覧・取り消しできない |
| NFR-04 | セキュリティ | 状態を変える API には CSRF 対策を行う |
| NFR-05 | 信頼性 | 1 つの予約が 2 回届かない |
| NFR-06 | 信頼性 | 一時的な LINE 側の障害では再送を試みる。チャネルトークン不正と月間上限到達では再送せず、その回の送信を止める |
| NFR-07 | コスト | Cloudflare と LINE の無料枠の範囲で運用する。Cron 1 回の CPU は無料枠で 10ms、サブリクエストは 50 までである。段階 3 で 1 件送信の CPU を測り、常に 10ms を超える場合は有料プランへこの要件を改める |
| NFR-08 | 運用 | LINE の無料送信枠（月 200 通）を全利用者で共有する。承認時に active 人数 × 月間上限が 180 を超える場合は承認しない |
| NFR-09 | 運用 | デプロイは main マージで自動実行する。手動デプロイはしない。D1 のマイグレーションもその中で適用する |
| NFR-10 | 操作性 | スマホ幅（375px）で全操作ができる |
| NFR-11 | 品質 | テストカバレッジ 80% 以上。測定対象は Worker と画面コンポーネントである。LIFF SDK そのものはモックする |
| NFR-12 | セキュリティ | ログに文面、ID トークン、チャネルアクセストークン、セッション秘密を出さない |

## 7. 受け入れ条件

| ID | 条件 | 対応要件 |
| --- | --- | --- |
| AC-01 | 同じ分に予約が 1 件なら、その分の Cron で本人の LINE に文面が届く。同じ分に複数あるときは 1 分に 1 件ずつ送る | FR-01〜03 |
| AC-02 | 送信後、一覧で「送信済み」になる | FR-05 |
| AC-03 | 取り消した予約は送られない。送信中は取り消せない | FR-06 |
| AC-04 | LINE のメニューから開くと、ログイン操作なしで自分の予約一覧が出る | FR-07 |
| AC-05 | スマホのブラウザから開いてもログインして使える | FR-08 |
| AC-06 | 未承認・却下の利用者は予約を作れない（API も 403）。却下すると送信待ちは消える | FR-10, FR-11 |
| AC-07 | 管理者以外は管理画面と管理 API を使えない（403） | FR-11, FR-16 |
| AC-08 | 月間上限に達した月の日時で予約しようとすると拒否される | FR-12 |
| AC-09 | 他人の予約 ID を指定して取り消そうとしても 404 になる | NFR-03 |
| AC-10 | 送信処理が途中で中断・再実行されても、同じ予約は 1 回しか届かない | NFR-05 |
| AC-11 | 退会すると予約が消え、予定していた分は送られない。管理者と却下済みは退会できない | FR-15 |
| AC-12 | 承認で active 人数 × 月間上限が 180 を超える場合、承認は 403 になる | FR-17, NFR-08 |

## 8. 前提と制約

- LINE 側のチャネル作成・LIFF アプリ登録・リッチメニュー設定は篠田が行う。
- Messaging API チャネルと LINE ログインチャネルは同じプロバイダーに作る。LINE の userId はプロバイダーごとに異なるため、別プロバイダーだと送信先が一致しない。
- 友だち追加していない、またはブロックしている利用者には届かない。LINE はその場合も 200 を返すことがある。届いたことは保証しない。
- LIFF アプリは「公開済み」にしないと、篠田以外は開けない。
- Preview 環境は Cron を動かさない。本番の D1 とチャネルアクセストークンを使わない。

## 9. 決定事項

評価で次のように確定した。

| 項目 | 決定 |
| --- | --- |
| 月間上限の既定 | 30。承認時に人数 × 30 が 180 を超えたら拒否する。友達を増やすときは既定を下げる |
| D1 スキーマ | 02 §4 を承認する。文面の長さは UTF-16 コードユニット。列の追加は初版ではしない |
| 送信済みの保持 | 期限は設けない。削除は取り消しと退会だけ |
| 予約の編集 | 作らない |
| 承認時の LINE 通知 | 送らない |
